Tools and Interactive Tutorials
===============================

To explore metasyn without deep-diving into the Python library immediately, we have created a set of tools and interactive tutorials.

Metasyn-tools
^^^^^^^^^^^^^

This is a set of tools that is installation-free and can be used without any Python knowledge. You can create synthetic datasets by setting the number of columns, rows and distributions.
The tools can be found on `GitHub <https://sodascience.github.io/metasyn-tools/>`__.

Interactive Tutorials
^^^^^^^^^^^^^^^^^^^^^

If you're new to Python or simply want to quickly explore the basic features of metasyn,
you can try our interactive tutorial. It provides a step-by-step walkthrough and example dataset
to help you get started.

We have three tutorials:
   - Getting started tutorial (`Google Colab <https://colab.research.google.com/github/sodascience/metasyn/blob/main/examples/1_getting_started.ipynb>`__) or (`GitHub <https://github.com/sodascience/metasyn/blob/main/examples/1_getting_started.ipynb>`__)
   - Metasyn with multiple tables (`Google Colab <https://colab.research.google.com/github/sodascience/metasyn/blob/main/examples/2_multiframe.ipynb>`__) or (`GitHub <https://github.com/sodascience/metasyn/blob/main/examples/2_multiframe.ipynb>`__)
   - Advanced and custom distributions (`Google Colab <https://colab.research.google.com/github/sodascience/metasyn/blob/main/examples/3_additional_features.ipynb>`__) or (`GitHub <https://github.com/sodascience/metasyn/blob/main/examples/3_additional_features.ipynb>`__)
